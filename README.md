# Peridot by Zee — frontend demo

Run `npm run dev`, then visit http://127.0.0.1:5173. No installation is required. You can also open dist/index.html directly.

Responsive boutique storefront recreated from the supplied design, with search, brand and arrival filters, sorting, favourites, product details, a quantity-controlled shopping bag and a demo checkout. Bag and favourites are saved locally in the browser. Newsletter and support interactions are explicitly simulated; there is no backend or payment integration.

Product and editorial imagery uses CSS crops of the supplied reference screenshot. Replace with original high-resolution photos for production. Google Fonts are optional; local serif and sans-serif fallbacks work offline.
